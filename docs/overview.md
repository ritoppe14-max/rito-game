# rito-game 概要

## 目的

ブラウザ上で遊べる、カスタム要素を含むポケモン対戦ゲームを提供する。プレイヤーはポケモン・技・特性・持ち物を選んでパーティを作成し、CPUまたは同じ端末の相手と対戦する。

## 想定利用者・利用場面

- PCまたはモバイルブラウザで、ポケモン対戦ゲームを遊びたい利用者。
- 追加ポケモン、専用技、独自特性、複数の対戦モードを試したい利用者。

## 現在の範囲

- ポケモン・技・特性・持ち物を選ぶパーティ編成。
- CPU対戦、同じ端末でのフレンド対戦、シングル／ダブル／トリプル／6体戦。
- ポケモンスタジアム、ポケモンタワー、ルナティックステージ、ダイマックス解放ステージ。
- メガシンカ、ダイマックス／キョダイマックス、テラスタル、独自技・独自特性・固有フォーム。
- ブラウザ保存と、初回オンライン起動後のオフライン起動。

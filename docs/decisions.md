# 判断記録

## 2026-09-27 / ゲームのソースを `src/` に集約

- 決定内容：ゲーム本体、対戦処理、テスト、補助ソースを `src/` に集約した。
- 理由：ソースと運用用ファイルを分け、テンプレートのディレクトリ規約に合わせるため。
- 検討した代替案：ルートにゲーム本体を維持する案。公開URLを保つため、ルートには `src/` を開く入口だけを残した。

## 2026-09-27 / 画像を `src/images/` に集約

- 決定内容：画像を `src/images/` に移し、参照を `images/` に統一した。
- 理由：`src/` を公開対象として扱う構成では、画像も同じ公開範囲に置く必要があるため。重複していた `public/image/` の同一画像も統合した。
- 検討した代替案：`src/` と同列に `images/` を置く案。公開時に別途コピーが必要になるため採用しなかった。

## 2026-09-27 / オフライン対応にService Workerを使用

- 決定内容：ルートの `sw.js` でゲーム画面・対戦処理・画像をキャッシュする。
- 理由：公開URLを初回オンラインで開いた後、通信なしでも遊べるようにするため。
- 検討した代替案：ローカルのHTMLファイルを直接開く案。ブラウザのService Worker制約により安定して利用できないため採用しなかった。

# rito-game 仕様

## 実行・公開

- 公開URL：`https://ritoppe14-max.github.io/rito-game/`
- ルートの `index.html` は `src/` のゲーム画面へ移動する入口。
- ゲーム本体は `src/index.html`、ダブル／トリプル戦処理は `src/multi-battle.js`。
- 画像は `src/images/` に集約し、ゲーム内では `images/` を参照する。
- `sw.js` はルートに置き、初回オンライン起動時にゲーム本体と画像をキャッシュしてオフライン起動を可能にする。

## 対戦

- 対戦形式：シングル、ダブル、トリプル、6体戦、CPU対戦、同じ端末でのフレンド対戦。
- 編成：ポケモン、技、特性、持ち物を設定し、最大3パーティを保存できる。
- コード配布ポケモンは対応コード入力後に解放・受け取りができ、解放前は一覧とCPU候補に表示しない。
- 特殊要素：メガシンカ、ダイマックス、キョダイマックス、電気テラスタル、各ポケモン固有の専用効果。
- ファクアのザシアン（コード `pokemon huxakua8`）：特性「ふとうのけん」は初回50エナジー、相手撃破で10回復、試合終了時に残量へ50補充（上限100、端末に保存）。5/10/15消費で攻撃・防御・特攻・特防・素早さを1/2/3ターン1.1/1.2/1.3倍にする。交代すると強化と溜め中の「せいなる剣」は解除。
- ファクアのザシアンの専用技：せいなる剣は20×4、20エナジーで20×6、選択から2ターン後に攻撃しゴーストにも命中。メタルクローは威力70・防御低下、強化時75+25の2回攻撃。じゃれつくは90、強化時60×2・防御低下。5枠目「王獣の剣」はエナジー0/10/20/30で威力50/80/100/140、再使用には追加20を消費し、前回当てた相手には威力1.3倍。持ち物「ふとうの剣」は固定。
- ファクアのファイアロー（コード `pokemon huxakua6`）：攻撃種族値115。特性「はやてのつばさ」は第6世代仕様とし、HPに関係なくひこう技の優先度を+1する。
- ファクアのファイアロー専用技：つばめがえしは威力60で、自分の残りHPが相手より多いと60×2回攻撃。ニトロチャージは威力85、命中時に与ダメージの30%を回復し、相手を倒すと素早さ+1・次回のニトロチャージで確定やけど。5枠目「フレアスイーパー」は威力130のひこう技で、実際に相手より先に動けたとき威力+30、相手をひるませる。
- 持ち物「ばくれつハチマキ」：最初に使用した技へ交代まで固定。物理攻撃の攻撃力を通常1.2倍、相手の行動前に攻撃できたターンは1.5倍にする。ファクアのファイアローの配布時に持たせる。
- 追加モード：ポケモンスタジアム、ポケモンタワー、ルナティックステージ群、ダイマックス解放ステージ。
- 進行データ：ブラウザの `localStorage` に連勝数・解放状態・タワー進行などを保存する。

## データと画面

- ポケモン、技、特性、持ち物、画面表示の主要データは `src/index.html` にある。
- `src/multi-battle.js` は複数ポケモンが場に出る対戦の行動・交代処理を担当する。
- `src/multi-battle.test.cjs` はNode.jsで主要な対戦機能とデータを検証する。

## 確認手順

`D:\git\rito_game\src` で実行する。

```powershell
node multi-battle.test.cjs
git -C .. diff --check
```

## 制約

- 画像の実ファイル名と、`src/images/` の参照名は完全に一致させる。
- 既存の未追跡ファイルを公開コミットへ含めない。
- Gitで追加するファイルは必ずパスを明示し、`git add -A` と `git add .` は使用しない。
